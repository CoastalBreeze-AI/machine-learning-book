# Errata

Corrections to *Machine Learning: Foundations, Algorithms, and Practice*, first printing, 2026, and to the code in this repository.

No errata have been recorded yet.

## Format

Each entry gives where the error is, what the book says, what it should say, and the printing or commit that fixes it. Newest entries go first.

```text
### [Chapter or appendix], Section N.M, page P (Listing N.M, if any)

- **Printed:** what the book says
- **Correct:** what it should say
- **Affects:** the book text, the code in this repository, or both
- **Fixed in:** the printing or commit that corrects it, or "not yet"
- **Reported by:** name, if the reporter wants credit (optional)
- **Date:** YYYY-MM-DD
```

To report an error, open an issue on this repository with the chapter, section, and page, and what you expected to see.
